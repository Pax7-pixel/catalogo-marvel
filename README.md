Catálogo Marvel - Fase 6 

Este é o meu primeiro projeto, desenvolvido para colocar em prática meus conhecimentos iniciais em HTML e CSS.

 Sobre o projeto:
 
O projeto consiste em um catálogo de filmes e séries da Fase 6 do Universo Cinematográfico Marvel, organizado em cards com imagens, títulos e anos de lançamento.

Tecnologias utilizadas

 HTML5
 CSS3
